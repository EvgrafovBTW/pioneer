# 0.1.0

- Added type-safe navigation with immutable route objects.
- Added independent navigation stacks with typed push, pop, replace, and reset operations.
- Added stateful multi-branch shells and single-stack shells.
- Added branch switching with preserved navigation and widget state.
- Added navigation between keyed branches with ambiguity detection.
- Added root navigation for pages displayed above a shell or bottom bar.
- Added deep-link parsing for cold and warm application starts.
- Added built-in system Back handling with extension and override callbacks.
- Added `BuildContext` navigation shortcuts.
